# Outils scolaires

Petits outils web pour réviser à la maison. Site statique, hébergé sur GitHub Pages :

**👉 https://le-syl21.github.io/outils-scolaires/**

## Défi Tables

Grille de multiplications dans un ordre mélangé à chaque partie, avec deux familles de niveaux :

- **Par cœur** — facile (1 à 10), moyen (3 à 12), dur (5 à 15), plus un raccourci « les difficiles » (6 à 9)
- **Calcul mental** — facile (5 à 15), moyen (13 à 18), dur (9 à 19)

Les tables se cochent aussi une à une, et on peut en ajouter d'autres (16 pour l'hexadécimal, par exemple).

- **Jouer** : grille à remplir à l'écran, chrono automatique, note ramenée sur 100, correction affichée case par case.
- **Scores** : classement au *temps corrigé* — chaque erreur coûte le temps de 5 cases justes, si
  bien que la pénalité pèse le même pourcentage pour un enfant rapide et pour un enfant lent.
  Scores enregistrés dans le navigateur, rien n'est envoyé sur Internet.
- **Imprimer** : génère des grilles vierges à remplir au stylo, comme la feuille d'origine.
