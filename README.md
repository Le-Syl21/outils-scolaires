# Outils scolaires

Petits outils web pour réviser à la maison. Site statique, hébergé sur GitHub Pages :

**👉 https://le-syl21.github.io/outils-scolaires/**

## Défi Tables

Grille des tables de multiplication de 1 à 10, dans un ordre mélangé à chaque partie.

- **Jouer** : grille à remplir à l'écran, chrono automatique, note sur 100, correction affichée case par case.
- **Scores** : classement des enfants et historique des parties (enregistrés dans le navigateur, rien n'est envoyé sur Internet).
- **Imprimer** : génère des grilles vierges à remplir au stylo, comme la feuille d'origine.
