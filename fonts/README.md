# Polices

**Marelle** — police cursive libre pour l'enseignement de l'écriture à l'école élémentaire,
version 1.005.

- `Marelle-Regular.woff2` — cursive seule
- `MarelleLIGNES-Regular.woff2` — cursive avec la réglure Seyes intégrée aux glyphes
